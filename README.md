public Sourcecode of BIT Typing rust version

How to build:

windows:
install rust & cargo
install python3.11+
run:
pip install customtkinter pillow pyinstaller pyinstaller-hooks-contrib

then run:
./build_win.bat

once the build finishes the output can be found in outputs/ folder

linux:
install rust & cargo
run:
./build_linux.sh

once the build finishes the output can be found in outputs/ folder
